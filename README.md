# 🛒 NexaCart – E-Commerce Dashboard & Shopping Platform

A modern and responsive e-commerce dashboard and customer shopping platform built using React.js.

## 🚀 Live Demo

https://nexacart-store.vercel.app

## ✨ Features

### 👨‍💼 Admin Dashboard

* Dashboard overview
* Product management
* Order management
* Customer management
* Analytics dashboard
* Sales reports
* Low stock alerts
* Search and filtering
* Dark mode

### 🛍️ Customer Shopping

* Customer View
* Product search
* Product details
* Product quantity selection
* Add to Cart
* Buy Now
* Shopping Cart
* Checkout
* Order placement
* Order status tracking

### 📊 Analytics

* Total sales
* Monthly revenue
* Total orders
* Top products
* Average order value
* Revenue chart
* Orders trend
* Product sales distribution
* Monthly sales report
* CSV report export

### 📱 Responsive Design

* Desktop responsive
* Mobile responsive
* Tablet friendly
* Mobile shopping experience

## 🛠️ Technologies Used
